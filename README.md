This is the real ultimate calculator for anyone doing FPGA design. Inputs can be twos-complement binary with binary point, hexadecimal, real, IEE754 single, or IEEE754 double. The outputs can also be twos-complement binary with binary point, hexadecimal, real, IEE754 single, or IEEE754 double. The GUI looks just like a normal calculator with a number pad, operators (+, -, *, /), data type selections and bit width fields.  The binary input to binary output data path is specifically designed to emulate fixed point math in an FPGA
